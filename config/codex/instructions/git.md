# Git

## Commands

- Don't EVER run any command that affect the remote origin!
- Only ever run commands like `git add` or `git commit` when the user EXPLICITLY asks for it!

## Commit messages

- Propose optional body for the commit if extra context would be useful to understand the commit
- Whenever code is generated by Codex in a commit-by-commit workflow, propose the corresponding commit message for every commit implemented
- Use conventional commit messages with the format: `docs(frontend): Add linting instructions in README.md`
